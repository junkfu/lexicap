### 詳細說明（Description）
```
看英文影集學英文，最大的敵人是「暫停」。查一個字要暫停、切分頁、打字、複製、貼到筆記軟體 —— 等你回到影片，劇情的節奏已經斷了。久了就乾脆不查了。

Lexicap 把這件事縮短成「點一下」。

■ 看片時

・點字幕上的任何單字 → 存下該單字 + 整句 + 前後句 + 時間點
・按 S → 存下當前正在播的整句
・按 A → 存下上一句

影片不會暫停。右下角只有一個一秒就消失的微型提示。你繼續看你的。

字幕由自繪的 Overlay 取代，並補上兩個原生字幕沒有的行為：句子講完會停留到下一句出現，滑鼠移入會凍結當前句 —— 讓你有時間看清楚、點得到。

■ 只在英文字幕時接管

切換成中文字幕或關閉字幕，擴充功能就完全休眠，畫面與沒安裝時一模一樣。

■ 事後

點擴充功能圖示打開筆記本：
・依影片自動分組
・全文搜尋
・按 ▶ 一鍵跳回影片的那一秒，重聽當時的語境
・匯出 Markdown 或 CSV，帶進 Obsidian、Notion、Anki 都行

■ 自動解釋，零設定

・單字 → 查詢隨擴充功能打包的離線英漢詞典，列出所有義項
・整句 → 使用 Chrome 內建的裝置端翻譯

不需要註冊帳號，不需要 API key，不需要付費訂閱。

■ 你的資料不會離開你的電腦

沒有伺服器、沒有帳號、沒有任何分析或追蹤。所有筆記都存在你自己瀏覽器的本機資料庫裡。詞典是離線的，翻譯在你的裝置上執行。

隱私權政策：https://github.com/junkfu/lexicap/blob/main/PRIVACY.md

■ 這不是什麼

・不是即時翻譯工具（看片當下不顯示翻譯，那會毀掉聽力練習）
・不是間隔重複／背誦系統
・不是雙語字幕外掛

■ 系統需求

Chrome 138 以上（句子翻譯功能依賴 Chrome 內建的 Translator API）。
目前支援 Netflix。

■ 開放原始碼

https://github.com/junkfu/lexicap
```

### 上傳順序與說明文字

依此順序上傳，第一張是輪播首圖：

| # | 檔案 | 建議的截圖說明 |
|---|---|---|
| 1 | `docs/store/01-notebook.png` | 筆記本：依影片分組、可搜尋、一鍵回跳原片 |
| 2 | `docs/store/02-capture.png` | 按 S 存下整句 —— 影片不暫停，只有一秒微型提示 |
| 3 | `docs/store/03-word.png` | 點字幕上的任何單字即可擷取 |

### 原始檔與處理紀錄

裁切後的來源圖保留在 `docs/store/src/`，要重做時不必重拍。

⚠️ 存進 repo 的是**已裁切**的版本，不是原始截圖 —— 這個 repo 是公開的，原始的桌面截圖含書籤列，不能進版控。原始檔請留在本機。

三張各做了什麼：

- **01** 原圖 1864×1386 直接等比縮放並左右補邊（補邊色 `#0f0f10` 即清單頁底色，接縫看不出來）。
- **02** 原圖中央有大面積的 NETFLIX 紅色字標，已裁掉上半部只保留字幕列、`Press S` 標註、控制列與「已存這句」提示。**裁掉字標是刻意的** —— 一來降低商標爭議風險，二來字標會搶走視覺焦點，讓截圖看起來像 Netflix 的廣告而不是你的產品。
- **03** 原圖是整個桌面截圖，含選單列、分頁列、網址列、**書籤列（有內部系統名稱）** 與 Dock，已裁到只剩播放器畫面。原圖那些書籤會洩漏你任職環境的內部工具名稱，不該出現在公開商店頁。

`c-goal-readme.png` 是 **03 的 README 專用裁切版** —— 原圖有大半是黑的，內嵌進 README 會佔掉一整屏卻只有底部四分之一有內容。商店用的 03 維持完整播放器畫面，與 02 的橫條構圖才有區別。

三張都沒有版權影像 —— 取的是淡出黑幕的片段，只有字幕文字與播放器 UI。

### 宣傳圖塊

來源是 `docs/store/src/promo-tile.html`，用 headless Chrome 以 2 倍解析度算圖再縮回目標尺寸：

```bash
./scripts/build-promo-tile.sh            # 440×280 小型圖塊
./scripts/build-promo-tile.sh marquee    # 1400×560 大型圖塊
```

文案改一個字不用重畫圖，改 HTML 再跑一次就好。兩種尺寸共用同一份版面。

用的是圖示的**琥珀色**而非清單頁的紅 —— 理由見 `scripts/build-icons.py` 開頭：擴充不該在視覺上看起來像 Netflix 官方出品。圖塊上也刻意不放任何第三方標誌。

圖示是用 CSS 重畫的，不是貼 `public/icon/128.png`（128px 放大到 2 倍畫布會糊）。幾何比例對齊 `build-icons.py`，**改圖示時兩邊要一起改**。

小型圖塊是商店列表用的；大型圖塊只有想被編輯精選時才需要，不上傳不影響送審。

### 要重做或補拍時

```bash
./scripts/make-store-screenshot.sh 輸入.png docs/store/04-xxx.png
```

腳本會等比縮放後補邊到 1280×800（不裁切、不變形）。第五個參數可換補邊色，播放器畫面用 `000000`，清單頁用 `0f0f10`。

⚠️ 補拍時記得：不要截到影片畫面內容，也不要把瀏覽器書籤列拍進去。

```
擷取影音字幕中的英文單字與句子，連同時間點儲存為可搜尋的個人學習筆記，並附上中文解釋。
```

**storage**
```
儲存使用者的擷取狀態與介面偏好設定於本機瀏覽器中。
```

**unlimitedStorage**
```
使用者的筆記與隨擴充功能打包的離線英漢詞典存放於 IndexedDB，資料量可能超過預設的儲存配額上限。
```

**主機權限 https://*.netflix.com/***
```
擴充功能需在影片播放頁注入自繪字幕 Overlay 並讀取該集的英文字幕軌，才能讓使用者點選單字進行擷取。所有功能僅在此網域運作，於其他任何網站均完全停用。
```

## 6. 之後要更新版本

1. 改 `package.json` 的 `version`（必須比線上版本大，不能重複或倒退）
2. `pnpm zip`
3. Dashboard → 套件 → 上傳新套件 → 送審

僅更新程式碼、未變動權限的版本，審核通常比首發快得多。
